# V0.12 — Food + Fruit Processing Foundation

This internal milestone extends the data-driven production layer for fruit processing and prepared foods.

- Fruit juice, jam and drying machine definitions.
- Hamburger, pide, lahmacun and pizza machine definitions.
- Recipe capacity target: 200+ recipes without changing core code.
- Products remain compatible with storage, market, orders and economy.
- Machines are movable unless explicitly marked fixed in placement rules.

These are development foundations, not a claim that final 3D assets, animations, balancing or device QA are complete.
